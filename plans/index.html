One set of rules for four permit offices

The four communities sit under four different code books. The sets are drawn to the newest of them, the 2021 International Residential Code with the 2020 National Electrical Code, and to the unamended 2021 energy code for Climate Zone 4A. Where an older local edition asks for less, the sheets still show the newer rule, so one plan set, one framing package and one trade scope work on every lot.

Editions were read from each jurisdiction's own page on November 17, 2026. Local amendments change details; the permit office has the last word.

Where the differences bite

  • Plumbing in the City of St. Louis follows the Uniform Plumbing Code. Vent sizing, trap arms and air admittance valves differ from the other three; the plumber lays out the venting there.
  • Ground-fault protection for a finished basement comes from the 2020 electrical code. The sheets show it everywhere.
  • Whole-house ventilation and the 3 ACH50 air-leakage test come from the 2021 codes. The sheets show both everywhere.
  • Insulation levels differ most of all. The sets use the 2021 values so one wall, roof and window package serves all four.

What a permit set still needs

  • Structural drawings sealed by a Missouri engineer or architect: foundation, framing, beams and headers, braced walls, truss and floor system layouts.
  • The site plan on a survey: setbacks, grades, drainage, utilities, driveway.
  • Energy compliance by the path the jurisdiction accepts.
  • Room-by-room heating and cooling loads and the duct design.
  • Local design criteria from the permit office: snow, wind, seismic category, frost depth, flood zone.
  • Sewer, water and utility approvals, and any subdivision or historic-district review.

How the sheets were made

  • Each sheet is generated from the 3D model's own walls, openings and fixtures, so the drawings and the walkthrough cannot drift apart.
  • Devices are placed by rule: outlet spacing, alarms, exhaust, drains and registers follow the code sections named in each sheet's notes.
  • Counts and loads in the tables are added up from what is drawn. Equipment sizes are planning figures and say so.
  • Four plans come in two versions, Standard and Upgraded. Each version has its own set.
