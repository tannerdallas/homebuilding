# Lookout Farmhouse mock site

Static mock listing site for two concept farmhouse plans (3,928 and 2,792 sq ft).

- `index.html`: the listing page
- `walkthrough/`: the room-by-room 3D walkthrough (three.js, loaded from a CDN)
- `img/`: renders and floor plans

No build step. Deploy the repo root as a static site (for example on Vercel with the default settings).

Concept plans and renderings only, not construction documents.
